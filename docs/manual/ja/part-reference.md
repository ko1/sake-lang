# 組み込みリファレンス

組み込みの型とモジュールごとに 1 章ずつ、その名前空間の**すべての操作**を載せます。章の見出しは操作の名前で、別名は 1 つの節にまとめています（`find, detect`）。各節の最初の行は正確な署名です:

- `Array.first(x, [Integer])`: `x` はその名前空間の型の値（主語）、`[T]` は省略できる引数、`*T` は任意個の引数、`[k: T]` はキーワード、` { }` は必須のブロック、` [{ }]` は省略できるブロック。
- `Integer[*Any]` のような `T[...]` は、T の値の **Array**（型付き Array）を作る構築子です。

本文では、操作が何をして何を返すか、引数の意味、結果が **nil** になる場合とそれを検査器がどの厳格レベルで報告するか、投げる**例外**、検査器が静的に弾くもの、主語を書き換えるか新しい値を返すか、Ruby の同名メソッドとの違い、を順に述べます。例の `# => 値` は実際の出力で、`ruby tools/check_reference.rb` がすべての例を `--strict=2` で走らせて照合し、署名と操作の網羅も確かめています（`ruby error` と書いた例は、弾かれる・失敗することを確かめたもの）。

章の順は、Kernel と例外、数、文字列と正規表現、並びと写像、時刻、入出力と OS、スレッドとソケットです。演算子（`+`、`<`、`[]`）の規則は[演算子と添字](05-operators.md)に、各型の値の性質は[値と型](03-values.md)にあります。
