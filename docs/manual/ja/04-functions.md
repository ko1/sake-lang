# 関数とブロック

## 関数

```ruby
def area(w, h) = w * h
def describe(n)
  return "negative" if n < 0
  Integer.to_s(n)
end
```

- **引数。** 必須の位置引数、その後に既定値付きの省略可能な引数（`def f(a, b = 1, c = b + 1)`）。Ruby と同じく、既定値は呼び出し時に、前の引数の後で、呼び出しが引数を与えなかったときに評価されます。キーワード引数は最後で、必須（`w:`）か既定値付き（`h: w`）、省略可能な位置引数と自由に混ぜられます。`def greet(name, greeting = "Hello", punct: "!")` は `greet("Ruby", punct: "?")` と呼びます。呼び出し先は実行前に分かるので、`k: v` はプログラムの検査時に名前で引数に届きます。未知のキーワード、重複、必須キーワードの欠落はエラーで、キーワード引数の無い関数への `k: v` もエラーです（暗黙の Hash 引数は無い。`Hash[k: v]` か Record `{k: v}` と書く）。いくつかの組み込みも Ruby のキーワードを取り、同じく検査されます（`Time.at(t, in: "+09:00")`、`Dir.glob(pat, base: dir)`。組み込みの一覧では `[k: T]`）。`f(k:)` は Ruby と同じく変数 `k` を渡します。引数は書いた順に評価されます。ブロック引数 `&b`（または `&`）は渡すことしかできません（下記）。
- **`*rest` と `**opts`。** 省略可能な引数の後の `*rest` は残りの位置引数を新しい Array に集めます（要素は 1 つの型、すべての呼び出しが渡すものの和。位置ごとの型を保つには Tuple を渡す: `notify(stock, ["AAPL", 120])` の後 `name, price = event`）。最後の `**opts` は引数でないキーワードを Symbol キーの Hash に集めます。どちらも呼び出し先が分かるので呼び出しの場で組みます（`**opts` を持つ関数はどのキーワードも受けるので、綴り間違いはそこではエラーになりません）。`*rest` の後の引数と、名前の無い `*` / `**` は拒否されます。`f(**opts)` と次の関数に渡すことはまだできません。呼び出しは必須の位置引数の数から全部まで（`*rest` があれば任意個）を与えます。mixin 関数の各定義は数、キーワード名、`*rest` / `**opts` の有無が一致しなければなりません。
- **返り値。** 最後の式の値、または `return expr`。`return a, b` は Tuple `[a, b]` を返します。
- **多相。** 関数は多相です。操作が受け付けるどんな引数でも動き、型エラーは失敗した操作で表面化します。
- **ローカル変数。** 各関数は自分のスコープを持ち、トップレベルのローカルには触れません。Ruby と同じく、最初の代入より前に読んだローカルは `nil` です。
- **再帰。** 可。深さ 10,000 を超えると `SystemStackError`。`bin/sake` は大きなスタックのスレッドでプログラムを走らせるので、Ruby のスタックではなくこの上限が効きます。長いバックトレースは短縮されます。

## ブロック

ブロックは、組み込みの操作か、yield するユーザ関数に渡せます。

```ruby
Array.map(xs) { |x| x * 2 }
Array.each(pairs) do |k, v| ... end
Integer.times(3) { p it }
```

- **値ではない。** ブロックは第二級です。格納も返却もできず、`proc`、`lambda`、`->` はありません。
- **渡す。** `def f(xs, &b) = Array.map(xs, &b)` は自分のブロックを別の呼び出しに渡します（`&` だけでも可）。`b` は `&b` としてしか使えず、ブロックの中の `break` はブロックが書かれた呼び出しを終えます。Ruby と同じく、ブロックを渡すだけの関数はブロック無しで呼べ、ブロックが要る呼び出しに何も渡さなければ `type` レベルのエラーです。
- **省略可能なブロック。** `block_given?` は今の関数がブロックを受けたかを言います。それを検査する関数はブロック無しで呼べます: `def info(msg = nil) = puts(block_given? ? yield : msg)`。検査器は呼び出しごとにブロックの有無を知っているので、取られる分岐だけを解析します（`&&`、`||`、`!` の中の `block_given?` も）。ブロック無しで届く `yield`（またはブロックが要る呼び出しへの `&b`）は `type` レベルのエラーで、実行時は `LocalJumpError`（rescue 不可）です。
- **引数。** `|a, b|` に名前を並べます。`it` と `_1` … `_9` は Ruby と同じです。
- **分解。** ブロックが 2 つ以上の引数を宣言し、1 つの Tuple か Array を受けると、その要素が引数になります（足りないものは nil、余りは捨てる。Ruby と同じ）。引数自身も分解できます: `|(name, n), i|`、`|acc, (k, v)|`。
- **rest 引数。** `|a, *rest|`（`|a, *rest, z|`、`|*all|` も）は残りの引数、または分解した Tuple / Array の残りの要素を新しい Array に集めます（`a, *rest = x` と同じ）。`|*all|` だけでは分解しません。
- **引数の数。** 引数無しのブロックは引数を無視します。それ以外で、引数の数が合わないブロック呼び出し（rest 引数があれば、他の引数より少ない）は `ArgumentError` です。
- **スコープ。** ブロックは囲むローカル変数を読み書きできます。
- **`next [v]`。** 今のブロック呼び出しを値 `v`（既定 `nil`）で終えます。
- **`return`。** ブロックの中の `return` は、Ruby と同じく囲む**関数**から返ります。
- **`break`。** ブロックの中の `break`（`break v`）は、ブロックを渡した呼び出しを終え、その値を `v`（または nil）にします: `Array.each(xs) { |x| break x if x > 10 }`。ブロックの中の `while` の中では `break` は `while` を抜けます。検査器は break の値を呼び出しの結果型に加えます。

`yield(args...)` は今の関数に渡されたブロックを呼びます。関数の外では静的エラーです。

> [!NOTE]
> ブロックの引数とローカルは、囲む関数のフレームに属します。ブロックを**スレッドで後から**走らせる関数（concurrent-ruby 風の `post { ... }`）に渡すと、スレッドが走る時点の値（ループ変数の最後の値）を読みます。Ruby ではブロック引数は呼び出しごとに新しい値です。スレッドを使わない限り違いは観測できません（`TODO.md`）。

## once

`once { ... }` はブロックの値を与えます。ブロックはプログラムのその場所に最初に到達したときに走り、その後そこを通るたびに、プログラム全体・すべてのスレッドで同じ値を返します。値の定数が無い Sake で、表や名前付きの値を 1 度だけ計算する方法です: `def crc_table = once { ... }`。値は Ruby の定数と同じく共有されます（`once` が保持する Array は変えられる）。計算中に自分の `once` に再び到達するブロックはプログラムの誤りです（`SystemStackError`）。実行前の検査では、型はそれを計算しうるすべての呼び出しでのブロックの結果の和です。
