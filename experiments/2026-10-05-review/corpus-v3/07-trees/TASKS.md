- bst_basic: String-keyed binary search tree with insert/update, search, delete by successor, in-order iteration, height, leaves, range query, floor and k-th smallest.
- heap_scheduler: Binary min-heap of Comparable jobs driving a priority CPU scheduler simulation parsed from CSV text, plus heap sort of integers.
- trie_autocomplete: Character trie with word frequencies and prefix pass-counts: insert, membership, prefix counts, ranked autocompletion, deletion with pruning, longest common prefix.
- segment_tree_stats: Recursive segment tree over daily sales giving range sum/min/max Records, point updates for corrections, sliding best-week search and range validation errors.
- expression_tree: Tokenizer and recursive-descent parser building an arithmetic expression tree (Num/Var/BinOp), with evaluation, minimal-parenthesis printing, simplification and symbolic differentiation, plus parse/unbound/zero-division errors.
- avl_tree: AVL tree with rotations counted in a stats record, insert/delete with rebalancing, invariant validation, level-order listing and sideways drawing.
- huffman: Huffman coding: frequency tally, ordered-queue tree construction with deterministic tie-breaking, code table, encode/decode round trip and compression report for several texts.
- filesystem_du: Builds a directory tree from a path/size listing, prints a du-style tree sorted by size, lists big directories, largest files, per-extension totals, and resolves cd paths with .. and errors.
- org_chart: Employee hierarchy parsed from a table: links reports, renders an ASCII org chart with headcount and cost rollups, chains of command, lowest common manager, and errors for unknown managers and reporting cycles.
- fenwick_ranks: Fenwick (binary indexed) tree with prefix/range sums and k-th search, used to count inversions (checked against brute force) and to maintain a live score leaderboard with ranks, percentiles and median.
- spanning_tree: Union-find forest (rank + path compression) used for Kruskal's minimum spanning tree over a road network; the tree is rooted by BFS, printed, and queried for paths with their longest leg; component counts for filtered roads.
- taxonomy_lca: Biological taxonomy tree from child/parent pairs: iterative DFS entry/exit times, binary-lifting ancestor table, LCA, distances, k-th ancestors, subtree sizes, and validation errors for malformed input.
- interval_bookings: Meeting-room booking backed by an interval tree (BST on start, augmented with max end): conflict detection with a Conflict exception, stabbing and range overlap queries, and free-slot listing.
- kd_tree: 2-d tree over European capitals parsed from CSV: median build, nearest-neighbour search with visit counting (checked against brute force), k-nearest with a sorted candidate list, and box range queries.
- btree: B-tree of configurable minimum degree (2 and 3) with search reporting depth, proactive node splitting on insert, duplicate rejection, in-order traversal via yield, level dump and range counting.
- dom_tree: Regex-driven parser for a small HTML subset into an element/text tree with parent links, pretty dump, tag counts, descendant CSS-like selectors (tag.class#id), text extraction and markup errors.
- decision_tree: ID3 decision-tree learner on the play-tennis dataset loaded from CSV into Hashes: entropy, information gain, depth-limited training, tree printing, node counts, accuracy and classification of unseen rows.
- lazy_seat_inventory: Segment tree with lazy range-add propagation (range min and sum) tracking per-day free seats on a train: reservations, cancellations, SoldOut errors naming the first short day, and occupancy statistics.
- tree_codec: Binary tree codecs: level-order "[1,null,2]" and preorder "#" formats with round-trip checks, mirror and symmetry tests, and height/diameter/max-path-sum computed in one recursive pass returning a Tuple; decode errors.
- quadtree: Point-region quadtree with capacity and depth cap: inserts labelled readings (with OutOfBounds errors), subdivides, dumps the tree, and answers rectangle queries counting visited nodes.
- rope_editor: Rope (binary concatenation tree of short string leaves) for text editing: split/concat-based insert, delete and replace edits with IndexError handling, char_at by weight descent, depth growth and rebalancing.
- traversals: Binary-tree traversal toolkit: recursive vs explicit-stack pre/in/post order, level order, zigzag, left/right views, vertical columns, root-to-node paths, and nodes at distance k using a parent map.
- merkle_sync: Merkle tree over 16-byte blocks with an FNV-1a hash written with bit operations: odd-level carry-up, inclusion proofs and verification (including a forged block), and replica diffing that descends only into differing subtrees.
- bill_of_materials: Bicycle bill of materials parsed from text into an assembly tree: validation with CycleError/UnknownPart, memoized cost rollup, indented explosion, raw-part requirements for an order, and where-used lookups.
- ip_route_trie: IPv4 routing table as a binary trie keyed by prefix bits: CIDR parsing with BadAddress errors, metric-based route replacement, longest-prefix-match lookups, route withdrawal and ordered route listing.
